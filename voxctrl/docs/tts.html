AI & VOICE / VOICE OUTPUT

Voice output (TTS)

Five on-device TTS engines, from a 1.2 GB expressive neural model down to a bundled formant synth. Pick one in Settings → TTS, or on the setup wizard's Voice step — which plays a sample from each before you commit to a download.

Engines

  • Breeze-TTS-2 — an open-weight bilingual (English/Chinese) model from BreezeBlue, built for low-latency real-time interaction and the most expressive of the five. It supports Voice Design: describe the speaker you want in natural language (breeze_tts_2.speaker_prompt) rather than picking from a list, or switch voice_mode to "clone" and use a reference clip. Its weights are gated and released under the BreezeBlue Research and Non-Commercial License — commercial use needs separate written authorization from RESONIA, INC.
  • Piper — a fast, local neural TTS system using ONNX models. VoxCtrl invokes the piper binary directly, pipes text to its stdin, and plays the raw 16-bit PCM it returns via rodio. The sweet spot for most machines at roughly 60 MB per voice.
  • Pocket-TTS — Kyutai's lightweight FlowLM + Mimi-codec model, ported to pure Rust on top of Candle (no Python, no ONNX, no subprocess). Instead of fixed voice embeddings, it clones a voice from a short reference audio clip at runtime. VoxCtrl ships a small built-in catalogue of reference clips (Alba, Anna, Vera, Charles, Michael) and also supports custom .wav voice clips. It streams generated audio frame-by-frame for low perceived latency, and the model can be pre-warmed on startup with the prewarm option. Requires a HuggingFace account that has accepted the license for the gated kyutai/pocket-tts model, plus a personal access token (hf_token).
  • Inflect-Micro-v2 — a ~9.4M-parameter VITS-family model (37.5 MB FP32, Apache 2.0) producing 24 kHz mono from a single fixed English voice. The smallest neural option, running in-process through ONNX Runtime with no subprocess. Graph signatures are verified at load; Settings → TTS → Inspect graphs reports the signature of a downloaded model.
  • eSpeak-NG — the default, because it is a system package with nothing to download. Used automatically if the selected engine is unavailable or no voice has been fetched. Quality is lower, but it is always there.
ⓘ One token for both gated engines. Pocket-TTS and Breeze-TTS-2 share a single tts.hf_token. The wizard's Voice step asks for it, and Settings → TTS edits the same value. An exported HF_TOKEN takes precedence: it is shown read-only in both fields and is never written to your config. A config written when each engine kept its own copy is migrated to this key on load.

GPU acceleration

Two engines can use a GPU:

  • Piper (tts.gpu) — appends a --cuda flag to the spawned Piper subprocess at runtime. If GPU initialization fails, Piper falls back to the CPU without crashing.
  • Breeze-TTS-2 (tts.breeze_tts_2.gpu) — loads the model onto a candle GPU device instead of the CPU. Needs the app built with the breeze-cuda (NVIDIA) or breeze-metal (macOS) feature on voxctrl-tts. Toggling it reloads the model, since the device is fixed at load; if the load fails, Breeze logs the reason and reloads on the CPU.

Pocket-TTS shares Breeze's runtime but exposes no GPU toggle of its own, and Inflect-Micro-v2 runs on ONNX Runtime's CPU provider — it is small enough that this is rarely the bottleneck.

Drop a .wav reference clip into the configured pocket_tts.voice_dir (default ~/.local/share/voxctrl/pocket-tts-voices/) to add a custom voice — no re-encoding or extra metadata needed. The filename (without extension) becomes the voice's id, e.g. narrator.wav adds "Narrator (Custom)". Naming a clip after a built-in voice (e.g. alba.wav) overrides that voice's bundled reference clip instead of adding a new entry.

Setup

  • Open Settings → TTS
  • Pick an engine (Breeze-TTS-2, Pocket-TTS, Piper, Inflect-Micro-v2 or eSpeak-NG) and a voice from the dropdown
  • Click ⬇ Download — progress bar in-app; Piper voices land in ~/.local/share/voxctrl/piper-voices/, Pocket-TTS model weights and voice clips are cached via the HuggingFace cache (~/.cache/huggingface/hub/)
  • For Pocket-TTS and Breeze-TTS-2, supply your HuggingFace token (hf_token) — one token covers both gated models
  • Click ▶ Test Voice to preview
  • Toggle Enable TTS

Stop key

Default KEY_ESCAPE. Press it from any window to interrupt TTS playback instantly — playback can be interrupted mid-generation, not just between utterances. Configure in Settings → TTS → Stop Key.

Response overlay

When enabled (tts.response_overlay), a green "SYSTEM RESPONDING" speaking pill slides up from the bottom of the recording overlay while TTS plays, with a live mini-equalizer and the active target label — distinct from the recording state so you always know when the app is speaking.
