GETTING STARTED / QUICKSTART

Quickstart

From zero to your first voice transcription in under five minutes. Since v0.4.0 a first-run wizard does most of this for you. Runs on Linux (Wayland + X11) and Windows 10/11.

1. Install

Linux: Download the AppImage from GitHub Releases, make it executable, and run it:

chmod +x VoxCtrl.AppImage
./VoxCtrl-x86_64.AppImage

That is the whole installation. voxctrl registers its own .desktop entry and icon under ~/.local/share/ on every Linux launch — no privileges, no install step, and nothing to undo later.

The only thing that can need a package manager is the helper that types text into other windows (wtype on Wayland, xdotool on X11). If it is missing, voxctrl says so and offers to install it. You can also do that step up front, which installs those packages and nothing else:

./VoxCtrl-x86_64.AppImage --install

Windows: Download the installer from GitHub Releases and run it. WebView2 is pre-installed on Windows 11; on Windows 10 it auto-downloads on first run.

2. Permissions (Linux)

None. Global shortcuts are registered with your desktop through the XDG GlobalShortcuts portal, so your desktop owns the key grab and tells voxctrl exactly one thing: that its own shortcut fired. There is no udev rule, no input group, no logout and no reboot. On Windows, hotkeys use Win32 hooks and also need nothing granted.

ⓘ Versions before v0.3.3 installed a udev rule that let every program running as your user read every keystroke on your system. The installer now removes that rule if it finds it, and never creates it. See Hotkeys.

3. Run the setup wizard

On a machine with no config, voxctrl opens a seven-step wizard instead of the settings window: engine and model size, hotkey gesture and binding, overlay, a live dictation test, and an optional voice. It downloads the model you pick before letting you continue, and writes each choice to disk as you make it — quitting halfway keeps what you picked.

Model sizes on offer for whisper.cpp, largest to smallest:

  • large-v3 (~3.1 GB) — maximum accuracy, wants a GPU or patience
  • medium (~1.5 GB) — close behind, still heavy
  • small (~466 MB) — good speed/accuracy balance for most hardware
  • base (~142 MB) — quick, usable for clear speech
  • tiny (~75 MB, default) — fastest, weak hardware and quick testing

Moonshine ships two sizes, tiny (~100 MB) and base (~250 MB), and keeps more of its accuracy in a noisy room. Models are stored in ~/.local/share/voxctrl/models/. Run the wizard again at any time with voxctrl --setup, or Settings → General → Open setup wizard. Full walkthrough: Setup wizard.

4. Speak

Click into any text field. Trigger the binding you made in step 3 — Ctrl+Space held down, if you took the wizard's suggestion. Speak. Release. Your transcript appears.

ⓘ If shortcuts cannot reach voxctrl, it says so in the tray and in a notification rather than silently ignoring your keypress, and starts working the moment that changes — without an app restart.
